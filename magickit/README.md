# MagicKit 🎨

A 100% free, client-side AI toolbox — no sign-up, no API key, no backend.

## Features
- 🖼️ **Image Generator** — text-to-image (FLUX) with retries and multiple ratios
- ✍️ **AI Writer** — open-ended text generation with optional system prompt
- 🎬 **Video Planner** — AI storyboard split + serial scene image generation

Everything runs in the browser against the free [Pollinations](https://pollinations.ai) API.
